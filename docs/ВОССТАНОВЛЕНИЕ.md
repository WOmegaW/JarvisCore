# Восстановление бота с нуля

Если пропал **сервер** (удалили аккаунт PythonAnywhere, что-то сломалось насовсем).
Компьютер для этого не нужен — всё делается в браузере, хоть с чужого ПК.

## Что понадобится
1. **Код** — уже лежит в GitHub: `https://github.com/WOmegaW/JarvisCore` (ветка `claude/telegram-expiry-tracking-bot-6eeciw`).
2. **Товары** — последний архив `mixalmacen-backup-ГГГГ-ММ-ДД.zip` из личного чата с ботом в Telegram.
3. **Секреты** — копия файла `.env` (см. «Как сохранить секреты» ниже). Если копии нет:
   токен бота можно выпустить заново в @BotFather (`/mybots` → бот → **API Token → Revoke**),
   остальные секреты генерируются заново командами ниже.

## Шаги (PythonAnywhere → Consoles → Bash)
Если аккаунт новый и логин другой — замените `carbonara`/`Carbonara` на свой и поправьте адреса
в `.github/workflows/tests.yml`, `.github/workflows/morning.yml` и `miniapp/tgcloud/lib/config.js`
(или попросите Claude сделать это).

1. Скачать код и библиотеки:
   ```
   cd ~ && git clone -b claude/telegram-expiry-tracking-bot-6eeciw https://github.com/WOmegaW/JarvisCore
   ```
   ```
   cd ~/JarvisCore && python3.12 -m venv ~/venv && ~/venv/bin/pip install -r requirements.txt
   ```
2. Вернуть секреты: Files → `JarvisCore` → создать файл `.env` и вставить сохранённое содержимое.
   Если сохранённого нет:
   ```
   echo "BOT_TOKEN=ТОКЕН_ОТ_BOTFATHER" > .env && echo "PROXY_URL=http://proxy.server:3128" >> .env
   ```
   ```
   echo "WEBHOOK_SECRET=$(python3 -c 'import secrets; print(secrets.token_urlsafe(24))')" >> .env && echo "DEPLOY_SECRET=$(python3 -c 'import secrets; print(secrets.token_urlsafe(24))')" >> .env
   ```
   и затем `echo "ALLOWED_CHAT_IDS=ID_ГРУППЫ" >> .env` (ID можно узнать командой `/id` в группе).
3. Вернуть товары: Files → `JarvisCore` → **Upload a file** → архив из Telegram, затем:
   ```
   ~/venv/bin/python -m bot.restore mixalmacen-backup-ГГГГ-ММ-ДД.zip
   ```
4. Сайт: вкладка **Web → Add a new web app → Manual configuration → Python 3.12**.
   Virtualenv: `/home/ЛОГИН/venv`. WSGI-файл заменить командой:
   ```
   printf 'import sys\nsys.path.insert(0, "/home/ЛОГИН/JarvisCore")\nfrom flask_app import app as application\n' > /var/www/логин_pythonanywhere_com_wsgi.py
   ```
   затем **Reload**.
5. Подключить бота к сайту:
   ```
   cd ~/JarvisCore && ~/venv/bin/python -m bot.set_webhook логин
   ```
6. Утренний будильник: на cron-job.org в задании «MixMarkt — утренний план» поменять адрес/секрет,
   если сменились логин или `DEPLOY_SECRET` (см. README → «Утренний план»).
7. Автообновление и утренний план: GitHub → Settings → Secrets and variables → Actions —
   обновить `DEPLOY_SECRET` (значение из `.env`) и `PA_API_TOKEN` (PythonAnywhere → Account → API token).
8. Мини-приложение: @BotFather → бот → настройки Mini App → адрес `https://логин.pythonanywhere.com/app`.
9. Проверка: в группе `/help` и `/app`; в GitHub → Actions → Morning plan → Run workflow (`1`).

## Как сохранить секреты (сделать один раз заранее)
PythonAnywhere → Bash:
```
cat ~/JarvisCore/.env
```
Скопируйте всё, что выведется, в надёжное место: менеджер паролей, заметку с паролем
или «Избранное» в Telegram. **Никому не пересылайте** — там токен бота.
